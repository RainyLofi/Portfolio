01. about.lua

      

        

          
Hey, I'm RainyLofi. I'm a software engineer and a Partner at Blueprint. Most nights that means Roblox Studio, rain on the window and a lo-fi playlist on loop.

          
I started as a kid in Roblox's Script Builder, making tools, weapons and admin tabs, then moved on to building and selling web tools for Roblox groups in Python, PHP and JavaScript. All in, that's more than 12 years of programming.

          
For the last six years most of that time has gone into Star Wars: Roleplay for GAR, a community of over 1.7 million members. Since 2022 I've been rebuilding it as a single codebase that powers seven connected places, alongside the API and Discord bot that run the community side.

          
I like owning a feature end to end: the server-side Luau, the UI players interact with, and the Node API and database behind it.

          
I do use AI tools (they're in the workflow list), but as tools, not as a substitute for knowing what I'm doing. Everything I ship gets reviewed and tested by me, and I can explain and debug every line of it.
